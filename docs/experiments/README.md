# Documentation Experiments

Use one Markdown file per design or pipeline experiment. Record the question,
hypothesis, input identifiers (never private URLs), configuration, code revision,
metrics, observations, and decision. Store large artifacts under an ignored local
`artifacts/` or `runs/` directory and link them by reproducible local convention.

Experiments may investigate future milestones but must not merge production
implementation before that milestone becomes current in `PLANS.md`.
